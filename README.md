# Практика к лекции 9: функциональные интерфейсы, Optional и Stream API

Шесть заданий по материалам лекции 9. Задания соответствуют слайдам
«Практическое задание 1–6» презентации и разбираются на занятии.

Каждая папка `task-NN-*` самодостаточна:

- `README.md` — постановка, указания и контроль;
- `src/` — скелет: записи предметной области, фиксированные данные и
  файл `TaskN.java` с методами `TODO` и автоматическим контролем в `main`.

## Требования

- Java 17+ (проверялось на JDK 21);
- сборщик не нужен — только `javac` и `java`.

## Как работать

1. Прочитайте `README.md` задания.
2. Скомпилируйте и запустите:

```
javac -encoding UTF-8 -d out src/*.java
java -cp out Task1
```

Флаг `-encoding UTF-8` обязателен: в исходниках есть русский текст.

3. Реализуйте методы, помеченные `TODO`. Запускайте контроль снова после
   каждого шага: `main` печатает `OK` для верных проверок и `FAIL` с
   ожидаемым значением для неверных.
4. Задание выполнено, когда все проверки — `OK`.

Пока `TODO` не реализованы, контроль печатает `FAIL ... реализуйте TODO` —
это нормальное состояние скелета.

## Задания

| Папка | Задание | Тренирует |
|---|---|---|
| `task-01-predicates` | Композиция предикатов для метрик | `Predicate`, `and`/`or`/`negate` |
| `task-02-pipeline` | Мини-стрим: конвейер Pipeline | fluent-цепочка, `Function`, `Predicate`, `BiFunction` |
| `task-03-optional` | Конвейер Optional для ночной смены | `flatMap`/`filter`/`map`/`orElse` |
| `task-04-report` | Отчет по инциденту | `filter`/`map`/`distinct`/`sorted` |
| `task-05-summary` | Сводка по хостам смены | `groupingBy`, `counting`, `summingInt` |
| `task-06-race` | Параллельная сводка и гонка | `parallelStream`, контракт параллельности |

Решений в репозитории нет — они разбираются на занятии.
