# Задание 4 · Отчет по инциденту

## Постановка

Реализуйте `slowestHosts`: хосты с задержкой **свыше 100 мс**, без
повторов, в лексикографическом порядке — **одним конвейером**.

Дополнительно (каждое — одним выражением):

- `slowCount` — количество медленных метрик без сохранения списка
  (`count`);
- `hasSlow` — есть ли медленные метрики (`anyMatch`);
- `firstSlow` — первая медленная метрика (`findFirst`).

## Указания

- Порядок ступеней: `filter` → `map` → `distinct` → `sorted` → сборка.
- `sorted` до `filter` — обработка отброшенных элементов: не делайте так.
- Сборка — `collect(Collectors.toList())` или `.toList()` (Java 16+).

## Контроль

```
javac -encoding UTF-8 -d out src/*.java
java -cp out Task4
```

При правильном решении:

```
OK   slowestHosts
OK   count
OK   anyMatch
OK   findFirst
```

`main` сверяет: `slowestHosts` → `[cache, db-1.prod, staging-db.prod]`,
количество — 4, наличие — `true`, первая медленная метрика —
`db-1.prod` с задержкой 120.

## Дополнительно

Сопоставьте ступени конвейера с шагами императивного решения из начала
лекции один к одному: декларативная версия не добавляет магии, а убирает
механику.
